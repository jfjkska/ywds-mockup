Mock-up

Image options

Four alternative styles for the page pictures. Each row shows the same four pages so you can compare.

A: Current

What the mock-up uses now: flat objects (open books, clipboard, envelope) on soft circles and green hills. Shown for comparison.

B: Landscape

Every picture is a Wolds scene drawn like the logo: layered green hills, a winding cream path, trees and a bird. One small detail hints at the page. The closest match to the logo.

C: Line drawing

Friendly navy sketches on a plain cream background, with very little colour. Calm and print-like.

D: Abstract shapes

No objects at all: soft overlapping circles and curves in the logo colours, arranged differently on each page. The most modern and least literal.

E: Photos

Real photographs. The frames below show the kind of photo that would go on each page.

These are empty frames, not real photos. Real photos would need a stock photo licence, or Natalie's own pictures (with written consent from anyone shown, and a parent's consent for any child).
